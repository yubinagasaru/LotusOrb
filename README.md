# LotusOrb
LotusOrb は、左右それぞれにトラックボールを有する、Lotus配列を採用した分割キーボードです。  

  
Build Guide: [JP](https://zenn.dev/yubinagasaru/articles/00e4f8b8c75949)  
販売: [Booth](https://yubinaga.booth.pm/items/7729916)

## ファームウェア

通常は **PMW3360用** のファームウェアを使用してください。[firmware/](firmware/) に左右用のUF2を置いています。`lotusorb_pmw3360_vial_left_scroll_reduced.uf2` は左スクロール量を減らした版です。

**PMW3389用は実験用** として、[firmware/pmw3389/](firmware/pmw3389/) に分けて管理します。通常版の左右用と、左スクロール量を減らした版を格納しています。通常の3360搭載キットには使用しないでください。
